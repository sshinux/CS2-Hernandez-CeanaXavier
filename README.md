# Electricity Bill Calculator
**A program that calculates the customer's total electricity consumption and total electricity bill.**

## Version 1 - Original Code WITHOUT Input Validation

- Inputs CUSTOMER NAME, PREVIOUS METER READING, AND CURRENT METER READING
- Calculates ELECTRICITY CONSUMPTION, AND TOTAL BILL
- Outputs customer's ELECTRICITY CONSUMPTION and TOTAL ELECTRICITY BILL

## Version 2 UPDATED
 - VALIDATES the input of
   1. name
   2. previous meter reading
   3. current meter reading
